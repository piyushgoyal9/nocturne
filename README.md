# 🎵 Nocturne

A modern music streaming web application built from scratch using HTML, CSS and JavaScript.

Nocturne is currently a frontend demo focused on building a functional music player and Spotify-inspired streaming interface.

## ✨ Features

- 🎵 Music playlist interface
- ▶️ Play / Pause
- ⏮ Previous song
- ⏭ Next song
- 🔀 Shuffle
- 🔁 Repeat
- ⏱ Current time and song duration
- 🎚️ Interactive progress bar
- 🔊 Volume control
- 🖱️ Click any song card to play
- 🖼️ Dynamic song artwork
- 🎶 Dynamic song title and artist
- 🟢 Active song highlighting
- 🔄 Automatic next song playback
- 📱 Responsive UI in progress

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- HTML5 Audio API
- SVG Icons
